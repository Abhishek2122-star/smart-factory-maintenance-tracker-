## 🎬 **ANIMATION EFFECTS**

### **Hover Animations**
```
Card Hover:
  Transform: Scale 1.0 → 1.05 (grows slightly)
  Shadow: Normal → Larger shadow
  Speed: 0.3s smooth
  Effect: Lifts off the page

Button Hover:
  Transform: Y → -3px (moves up)
  Shadow: Normal → Larger shadow
  Speed: 0.3s smooth
  Effect: Button appears to press

Link Hover:
  Border: None → Colored border
  Color: White → Cyan glow
  Speed: 0.3s smooth
  Effect: Glows and stands out
```

### **Focus Animations**
```
Input Focus:
  Border: Gray → Purple
  Box-shadow: None → Purple glow
  Background: White → Light purple
  Speed: 0.3s smooth
  Effect: Highlights field
```

### **Alert Animations**
```
Alert Appear:
  Transform: X:-20px → 0px (slide in from left)
  Opacity: 0 → 1 (fade in)
  Speed: 0.3s ease
  Effect: Smooth appearance
```
