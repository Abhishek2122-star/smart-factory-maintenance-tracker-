## 🎯 **COMMON TASKS**

### **Add a Record**
1. Click "Add Maintenance"
2. Fill in machine name, date, readings, issue, technician
3. Click "SUBMIT"
4. Done! ✅

### **View Records**
1. Click "Reports"
2. See table of all records
3. Use search/filter
4. Done! ✅

### **Delete a Record**
1. Find record in Reports
2. Click red "DELETE" button
3. Confirm delete
4. Done! ✅

### **Mark Record Complete**
1. Find record in Reports
2. Click green "COMPLETE" button
3. Record marked done
4. Done! ✅

### **Export to PDF**
1. Go to Reports
2. Click green "Export to PDF"
3. PDF downloads
4. Done! ✅

### **Export to CSV**
1. Go to Reports
2. Click blue "Export to CSV"
3. CSV downloads
4. Done! ✅

## 🆘 **TROUBLESHOOTING**

**App won't start?**
```powershell
# Clear cache and reinstall
rm -r node_modules
npm install
npm start
```

**Port 3000 in use?**
```
→ App automatically uses 3001
→ Open: http://localhost:3001
```

**Data not saving?**
```
→ Check browser localStorage
→ Try clearing cache
→ Refresh page
```
