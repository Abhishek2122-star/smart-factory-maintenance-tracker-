## 📋 **CUSTOMIZATION GUIDE**

### **To Change Primary Colors**
```css
/* Update these gradients */
--primary-start: #667eea;
--primary-end: #764ba2;

/* Update in App.css */
background: linear-gradient(135deg, var(--primary-start) 0%, var(--primary-end) 100%);
```

### **To Change Accent Color**
```css
/* Change cyan accents */
border-color: #00d4ff; → your color
```

### **To Adjust Shadow Intensity**
```css
/* Reduce shadow */
box-shadow: 0 6px 20px rgba(0, 0, 0, 0.2);

/* Increase shadow */
box-shadow: 0 12px 40px rgba(0, 0, 0, 0.35);
```
